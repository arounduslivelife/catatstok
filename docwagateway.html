Send Message

Send a plain text message to a WhatsApp number.

POST GET https://app.botgateway.my.id/send-message

Request Parameters

Parameter Type Required Description
api_key string Yes API Key
sender string Yes Number of your device
number string Yes Recipient number e.g. 72888xxxx | 62888xxxx
message string Yes Message to be sent

JSON Request Example

request.json 
{
  "api_key": "1234567890",
  "sender": "62888xxxx",
  "number": "62888xxxx",
  "message": "Hello World"
}

URL Request Example

GET 
https://app.botgateway.my.id/send-message?api_key=1234567890&sender=62888xxxx&number=62888xxxx&message=Hello World

Send Media

Send image, video, audio, or document via a direct media URL.

POST GET https://app.botgateway.my.id/send-media

Request Parameters

Parameter Type Required Description
api_key string Yes API Key
sender string Yes Number of your device
number string Yes Recipient number e.g. 72888xxxx | 62888xxxx
media_type string Yes image video audio document
caption string No Caption / message
url string Yes Direct URL of the media file

Make sure the URL is a direct link. Links from Google Drive or other cloud storage are not supported.

JSON Request Example

request.json 
{
  "api_key": "1234567890",
  "sender": "62888xxxx",
  "number": "62888xxxx",
  "media_type": "image",
  "caption": "Hello World",
  "url": "https://example.com/image.jpg"
}

URL Request Example

GET 
https://app.botgateway.my.id/send-media?api_key=1234567890&sender=62888xxxx&number=62888xxxx&media_type=image&caption=Hello World&url=https://example.com/image.jpg

Send Poll

Send an interactive poll message with multiple answer options.

POST GET https://app.botgateway.my.id/send-poll

Request Parameters

Parameter Type Required Description
api_key string Yes API Key
sender string Yes Number of your device
number string Yes Recipient number e.g. 72888xxxx | 62888xxxx
name string Yes Poll question or name
option array Yes Poll answer options
countable string 1 | 0 Yes 1 = single vote only, 0 = multiple votes allowed

JSON Request Example

request.json 
{
  "sender": "6281284838163",
  "api_key": "yourapikey",
  "number": "082298859671",
  "countable": "1",
  "name": "what color do you like?",
  "option": ["red", "blue", "yellow"]
}

URL Request Example

GET 
https://app.botgateway.my.id/send-poll?sender=6281284838163&api_key=yourapikey&number=082298859671&name=what color do you like&option=red,blue,yellow

Send Button

Send an interactive button message supporting reply, call, URL, and copy actions.

POST GET https://app.botgateway.my.id/send-button

Request Parameters

Parameter Type Required Description
api_key string Yes API Key
sender string Yes Number of your device
number string Yes Recipient number e.g. 72888xxxx | 62888xxxx
message string Yes Text of message
button array Yes Button array, max 5
footer string No Footer text of message
url/image string No Image or video URL

Button types supported: reply, call, url, copy.

JSON Request Example

request.json 
{
  "sender": "6281284838163",
  "api_key": "yourapikey",
  "number": "082298859671",
  "url": null,
  "footer": "optional",
  "message": "Halo, ini pesan button",
  "button": [
    { "type": "reply", "displayText": "mantaps" },
    { "type": "call", "displayText": "mantaps", "phoneNumber": "082298859671" },
    { "type": "url", "displayText": "mantaps", "url": "https://google.com" },
    { "type": "copy", "displayText": "mantaps", "copyCode": "xxxx" }
  ]
}

URL Request Example

GET 
https://app.botgateway.my.id/send-button?sender=6281284838163&api_key=yourapikey&number=082298859671&url=&footer=optional&message=Halo,ini pesan button&button=button 1,button 2,button 3

Create User

Create a new user account with subscription and device limit settings.

POST GET https://app.botgateway.my.id/create-user

Request Parameters

Parameter Type Required Description
api_key string Yes API Key
username string Yes Username, no special characters
password string Yes User password
email string Yes Email address
expire number Yes Subscription expiry in days, e.g. 30
limit_device number No Max allowed devices, e.g. 10

JSON Request Example

request.json 
{
  "api_key": "1234567890",
  "username": "magd",
  "password": "12345678",
  "email": "ttmttxx@xx.com",
  "expire": "30",
  "limit_device": "10"
}

URL Request Example

GET 
https://app.botgateway.my.id/create-user?api_key=1234567890&username=magd&password=12345678&email=ttmttxx@xx.com&expire=30&limit_device=10

Create Device

Register a new WhatsApp device under a user account.

POST GET https://app.botgateway.my.id/create-device

Request Parameters

Parameter Type Required Description
api_key string Yes User API Key
sender string Yes Unique sender ID, min. 8 characters
urlwebhook string No Webhook URL for incoming message callbacks

JSON Request Example

request.json 
{
  "api_key": "1234567890",
  "sender": "6282298859671",
  "urlwebhook": "https://yourdomain.com/webhook"
}

URL Request Example

GET 
https://app.botgateway.my.id/create-device?api_key=1234567890&sender=6281234567890&urlwebhook=https://yourdomain.com/webhook

Webhook Example

Webhook is a feature that allows you to receive a callback from our server when a message is incoming to your device. You can use this feature for made a dinamic chatbot or whatever you want.

We will send a POST request to your webhook url with a JSON body. Here is an example of the JSON body we will send:

        
{
  "device" : "your sender/device"
  "message" : "message",
  "from" : "the number of the whatsapp sender",
  "name" : "the name of the sender",
  "participant" : "sender number if group",
  "ppUrl" : "url profile picture sender",
  "media" : [
    "caption" : "caption, equal to message",
    "fileName" : "xxxx.xx",
    "stream" : [
        "type" : "Buffer",
        "data" : "xxxx"
        ]
    ],
    "mimetype" : "image\/jpeg" // depends to media type, could be image,document,audio etc
    ] // null if no media
}
